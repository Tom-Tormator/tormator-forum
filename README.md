# Tormator Forum
This isn't your dad's forum software...

Tormator Forum is blazing fast PHP forum software handcrafted in the modern era. Unladen by legacy technical debt, Tormator Forum integrates state of the art security mechanisms with a clean and feature-rich modern take on forum software. We do this without compromising on any traditional systems or features that make forum software what it is.

The software is extensible, lightweight, efficient, and intuitive. The UI is simple and clutter-free, while still looking beautiful. This all embodies the Tormator philosophy.

Choose from a beautiful set of themes (up and coming) to make up your forum's decor and give it the unique aesthetic that you are looking for. Configure your forum just the way you want it with our extensive set of configuration options. Get froggy and go hog wild with customization!

We firmly believe that software is art and hence should only be created by human beings. That is why contributions made using generative AI (such as LLMs) are prohibited in this and every Tormator project.

## Requirements
- `PHP 7.3.0+`
- `php-mysql`, `php-gd`
- `MySQL` compatible database software (e.g. `MariaDB`)
